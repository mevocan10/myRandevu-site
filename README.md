# myRandevu landing page

Bu klasör `myrandevu.tr` için hazırlanmış statik landing page dosyalarını içerir.

## GitHub Pages'e yükleme

Repodaki mevcut `index.html` dosyasını bu klasördeki dosyayla değiştirin ve aşağıdaki dosyaları repo köküne ekleyin:

- `index.html`
- `style.css`
- `script.js`
- `favicon.svg`

GitHub Pages zaten `main / (root)` üzerinden yayındaysa ekstra ayar gerekmez.
